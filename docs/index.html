YouTube Automation Agent

An end-to-end pipeline that researches a topic, writes the script, narrates it, sources matching footage, burns in captions, and publishes — for both Shorts and long-form documentary videos.

View on GitHub Setup guide

Two pipelines, one codebase

Shorts run unattended. Long-form stops for a human before anything goes live.

Fully automated

Shorts — 1080×1920

Picks a topic, writes a ~60-second script, narrates it, assembles vertical video with burned-in captions over stock or gameplay footage, and publishes on a daily schedule. No human in the loop.

Review gate

Long-form — 1920×1080

A 7-chapter outline, written chapter by chapter to reach ~3,000 words. Each chapter gets its own footage, weighted to its share of the narration. Renders to a review folder and stops — nothing uploads until you approve it.

How a video gets made

Each stage is an agent; the scheduler chains them and retries transient failures.

topic selection  →  script writing  →  thumbnail  →  SEO  →  production  →  publish
     │                    │                                      │
     │                    │                                      ├── narration (TTS)
     │                    │                                      ├── footage sourcing
     │                    │                                      ├── caption track
     │                    │                                      └── FFmpeg assembly
     │                    └── LLM via local router, direct-provider fallback
     └── weighted angles × real view-count performance

What makes the long-form path different

Beat-matched footage

Every chapter carries its own search query, so visuals change with the story instead of looping one background. Clip duration is weighted to the chapter's narration length.

Word-level captions

whisper.cpp transcribes the rendered narration to word timings, producing highlight-style captions burned into the frame.

Chapter-wise writing

Asking a model for 3,000 words in one call reliably undershoots. Writing seven ~400-word chapters against an outline does not.

Quota-aware narration

Long-form narrates with edge-tts — free and unmetered — because the Gemini TTS free tier allows only 15 requests a day.

Performance feedback

Real view counts per angle produce a 0.5×–2× weighting on future topic selection, applied only after an angle has 3+ published videos.

Honest analytics

When the Analytics API is unavailable, data is skipped rather than simulated. The system never optimises against invented numbers.

Quick start

Needs Node.js 18+, FFmpeg, whisper.cpp, and free-tier API keys.

git clone https://github.com/strangedeev/youtube-automation-agent.git
cd youtube-automation-agent
npm install

# credentials (gitignored — never commit the filled-in copy)
cp config/credentials.example.json config/credentials.json

# whisper model for captions (~141 MB)
mkdir -p models
curl -L -o models/ggml-base.en.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.en.bin

npm start   # dashboard + API on http://localhost:3456
Publishing is irreversible. Videos go live using the channel.defaultPrivacy value in your credentials file. Set it to unlisted or private while you are still testing.

Known limitations

Stated plainly, so nothing here is a surprise after you clone it.

  • Stock footage is era-limited. Historical topics sometimes return plausible but anachronistic clips. Query wording steers this; it won't be perfect.
  • Thumbnails are procedural — a stock image plus a text overlay. Fine for Shorts; for long-form, expect to replace them by hand.
  • Encoding is slow. A 17-minute 1080p render takes roughly 20 minutes on an M-series Mac alongside other services.
  • Outstanding dependency advisories, mostly in the sqlite3 → node-gyp build toolchain; fixes need breaking major upgrades.
  • No automatic quality gate on long-form — a human watches it before approval.
